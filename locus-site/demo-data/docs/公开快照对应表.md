## 四、局部引用加载失败（R07）

图形/贯通链为**可选展示增量**：文件缺失不阻断工作台启动。对应区域显示「该区域暂时加载失败（引用文件不可读）」并提供「重试读取该区域」，点击后**重新读取该文件**恢复（旁路启动缓存，见 `display-api.js` 的 `reloadFigures/reloadChain90`）。实测：拦掉 `chain-90d.json` → 页面其余部分与样本 ZIP 正常 → 解除拦截至重试 → 恢复 6 跳。
