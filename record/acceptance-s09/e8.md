## 4. 缺陷（1 项，非阻断 E8 核心，但违反手册 §B.1 红线）

**D2 · 个人模式下「文献库」硬编码 `/demo-data`（展示数据混入风险）**
- 复现：个人源（trial 构建 + 本地后端 5190）→ 点导航「文献库」→ 观察到向 `/demo-data/snapshot/*` 发起请求（e8-proxy.txt 计 15 次，本地 404）；面板回落提示「文献库模块未随本次构建提供（/library），或预置快照缺失。」
- 根因：`sciworkbench/public/app.js:1100` 对 library 分支**写死** `baseUrl: "/demo-data"`，未按 `DISPLAY_CFG` 区分模式。
- 影响：违反手册 §B.1「个人文献库随课题切换读取当前课题，**禁止写死 `/demo-data`**，禁止用展示数据兜底」；当前因本地无 `demo-data` 目录而 404 掩盖，一旦部署环境存在 `/demo-data` 即可能**用展示数据兜底个人 API 失败**。
- 负责角色：**D（app.js 文献库接线）**。建议：仅 `DISPLAY_CFG` 存在时用 `/demo-data`，否则读在线接口或显式「个人模式暂不提供」。
- 说明：该缺陷仅出现在**新增的「文献库」面板**；工作台既有各视图（文献卡/表格/方案图/结果/回查）两源无混入（见 §3）。
