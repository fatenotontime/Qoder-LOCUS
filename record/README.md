# record 目录说明

本目录记录「2026 Qoder 高校创造力大赛」参赛全过程。

## 目录结构

- `00_competition_brief.md` — 比赛规则速查（从官网提炼）
- `sessions/` — 每次会话的过程记录（会话日志、页面快照）
- `screenshots/` — 关键节点截图
- `submission/` — 最终作品帖草稿及相关材料（后续按需创建）

## 约定

1. 每次会话新增一份 `sessions/YYYY-MM-DD_session-NN.md`，记录本会话做了什么、结论、待办。
2. 关键节点（报名、部署上线、作品帖发布、阶段验证）截图存 `screenshots/`，命名 `NN_描述.png`。
3. 页面结构快照（无头抓取）存 `sessions/page_*_snapshot.txt`，作为截图失败时的兜底证据。
4. 所有产物落在本 record 目录内，源码项目在仓库其它目录（见根目录 `personal agent/`、`sciworkbench/`）。
