1. 工作区写源码 → build 出静态输出目录（`prepare_site` 要的是构建产物目录，非源码根）。
2. Desktop 用 `open_design_workbench` 建 `.站点名.qoder.site` 描述符。
3. `prepare_site` → 打包上传为不可变草稿（创建云端项目、消耗配额）。
4. `publish_site` → `get_publish_status` 确认 `published: true` → `show_publish_confirmation` 收尾交付。
5. 得到公网地址，满足比赛「评委点开即用」要求。
- 后端需求（sciworkbench 可能涉及）：Function(`functionDirectory`) / Database / Storage / Secret / AI(走 sites-build-agent-app)。密钥只传 Secret 名不传值。
- 先跑 `get_context` 探测工作区是否已绑定过 site，避免误建新站。
