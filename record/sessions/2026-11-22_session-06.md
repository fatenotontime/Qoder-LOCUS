## 2. M3：五类方法与前提判断

- 固定五类：描述统计 / 时间·参数趋势图 / 线性拟合·校准 / 独立两组比较 / 配对前后比较；每条含稳定 id、版本、适用问题、输入要求、前提检查项、缺信息问题、具体工具路径与函数、操作步骤、需填写参数、产物清单、验收项、常见误用、合成示例。
- 工具路径为**可核实**内容（pandas / matplotlib / scipy 具体函数名与参数），并记录工具版本；`runtimeStatus: verified`。
- 判断三态 `ready / needs_info / not_applicable`：关键前提须**已确认**才给可执行步骤；`inferred`（机器推断）不自动视为确认；未知不触发 `not_applicable`。一条方法被阻断不影响其他方法。
- 缺口（按提示词 §4.3/§6 硬约束）：独立性未知→**不下发**完整两组检验步骤；无配对键→不按行配对（改推独立两组）；x 常量→线性拟合 `not_applicable`；两组确认非独立→独立两组 `not_applicable`。
- 快照序列化含目录版本/逐条 hash、收到的事实与确认状态、问题与判断；**已序列化快照不因后续目录编辑而漂移**；M2 画像缺失显式标 `profileMissing`，有则原样带上（不杜撰）。
- 边界：不写 `AnalysisTaskRecord`、不确认知识、不调模型、不改 `reproducible` 含义。

## 3. M5：离线评测

- 四类任务映射固定：文献结构化→`knowledge_struct`、OCR→`handwriting_ocr`、暂停恢复→`pause_assist`、变更影响→`impact_assess`（明确不混用 `literature_extract`）。
- 基线从只读 `TASKS` **冻结 system/schema 正文 + hash + 代码基线**（`knowledge_struct` 用版本常量 `knowledge_struct/v1`；其余如实标「未定义版本常量，以正文 hash 冻结」，不统一编造 promptVersion）。
- 记录结构：样本（id/任务/调试·留出/来源·许可/synthetic·real/原始输入及 hash/人工验收点）、提示词（任务/版本/正文/hash）、处理（处理器版本/实际发送输入及 hash/参数；OCR 记图像内容 hash）、运行（runId/模型/已知参数/模拟·真实/时间/状态/未修补原始输出/解析或错误）、判断（逐条验收项/自动规则/人工判断与理由/失败类别/修订历史，**未审阅保持未审阅**）、比较（两 run 引用/对应样本与输入/可比性说明/逐项新增失败·修复·仍失败·待人工判断）。
- 自动规则限结构、必填项、禁止字段（如 `knowledge_struct` 禁 `audit/revision/stableId/history`）；语义项（引文逐字、OCR 数值与未知、影响是否承认未知）**仅供人工判断**。
- 可比性：仅改一个提示词因素（system 或 schema）且其余同条件→可比；换模型/参数/处理版本/样本集合或**样本输入 hash**→明确不可比并列出差异。
- CLI：`check`（离线重做解析与规则，不调模型）、`compare`（JSON + 可读 Markdown，逐样本分类）、`judge`（登记判断，保留历史，不改原输出）、`freeze`（冻结基线）。退出码：`0` 正常无可留待审、`2` 输入/格式错误、`3` 已生成报告但含待审（**语义待审不伪装通过**）。输出路径一律显式；不执行报告文本/脚本、不联网。
