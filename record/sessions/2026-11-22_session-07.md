## 4. 导出接口（供集成者直接调用，均在 `services/import-formats/index.ts`）

- `new OriginalStore(rootDir)`：`save(bytes, fileName, {maxBytes?}) → SavedOriginal`、`retrieve(id) → Uint8Array`、`meta(id)`、`has(id)`、`idFor(bytes)`。
  - 标识 `orig_<sha256(原始字节)>`；同字节稳定复用；同名不同内容不覆盖；落盘持久，重建实例可取回。
- `parseBytes(bytes, fileName, options?, sourceId?) → Promise<ParseResult>`
- `parseOriginal(store, id, options?) → Promise<ParseResult>`
- `listWorkbookSheets(bytes, options?) → Promise<SheetInfo[]>`
- `profileGrid(grid, {headerRows?}) → TableProfile`
- `cellOriginAt(grid, row, col)`：由网格推导单元格原始位置（xlsx→A1；delim→0 基记录/字段；docx→表内行列）。
- 类型与常量：`PARSE_PROTOCOL_VERSION = "m-import/1"`、`ParseStatus`、`ParseResult`、`GridTable`、`TableProfile` 等（`contracts.ts`）。

`ParseOptions`：`headerRows`、`sheet`、`originalMaxBytes`、`archiveExpandMaxBytes`、`outputMaxCells`、`outputMaxChars`。

## 5. 约定

- **原件与派生分列**：`originalHash` = 原始字节 sha256；`derivedHash` = 派生内容 sha256。
- **坐标基准**：内部索引 0 基；对外编号（PDF 页码、TXT 物理行号、XLSX A1）1 基。CSV／TSV 位置为 0 基**逻辑记录/字段**，引号内换行不冒充物理行号。
- **原件根目录**：由调用方显式传入（测试用临时目录）；文件名仅作元数据。
- **状态**：`ok`／`partial`／`needs_ocr`／`unsupported`／`failed`；空结果不冒充成功。

## 7. 未覆盖限制（如实列出）

- **PDF 内嵌 CJK 未覆盖**：标准字体不含中文，夹具以非 ASCII 拉丁/符号（é ü ° × ± µ）验证 Unicode 通道；真实中文在 DOCX／TXT 夹具覆盖。解析器对编码不敏感（pdfjs 返回 Unicode 串）。
- **PDF 阅读顺序**为内容流顺序，多栏/复杂版面可能与视觉顺序不同（已发警告）。
- **扫描 PDF 不做 OCR**（返回 needs_ocr，不自动处理）。
- **DOCX 复杂对象**（图片/文本框）仅警告不杜撰；嵌套表格只取外层文本。
- **XLSX** 不做公式重算、不做 XLS/XLSM/宏、不做任意编码探测；日期按显示文本＋numFmt 保留，不作时区/单位换算。
- **压缩展开量**以 zip 条目 originalSize 之和预检（不解压内容）；无法判定时回落输出上限。
