# LOCUS 测试样本验收包 v1

**用途：开发验收交付包，不是模型上下文。** 评委/模型每次仅取得相应目录中的 `evaluator*.zip`；developer-reference 单独保管，不得注入评委模型。Step 3 的作者外部图作为用户主动提交材料，不能预载到初始观察上下文。所有三案均来自 DaRUS DOI 10.18419/DARUS-3337 同一个硕士论文/JupyterBook数据集，不是多领域 benchmark。所有分发按 DaRUS CC BY 4.0，署名 Max Häußler / DaRUS / DOI 10.18419/DARUS-3337，并保留各案注明的数据提供者和改编声明。

## 候选包

1. **01_SLAC**：`evaluator-safe-input.zip`。主推荐。ABTS 氧化小型漆酶 SLAC 的 pH/温度动力学，涵盖 timecourse、标准曲线、光谱、CSV条件记录、方法节选和作者校准外部图。原作者完整 notebook 与结果单独在 developer-reference。评委提交作者图须在 Step 3 手动附加。
2. **02_chymotrypsin**：`evaluator.zip`。HSA(WT)/HSA(M3)抑制实验和 p-NA标准数据。作者数据已扣空白，不是仪器原始采集文件；notebook答案独立保存。实验数据提供者 Marwa Mohamed（以子包说明为准）。
3. **03_CotA**：`evaluator.zip`。CotA预孵育吸附/时间依赖失活实验，CSV为原工作簿只读派生；不含并行70分钟底物动力学实验。来源记录由 Max Häußler 提供，实验数据提供者 Paulo Durão。作者外部图是参照材料，不是标准答案。没有原始纸质手写记录，不能称作 OCR benchmark。

## LOCUS评委工作路线

导入对应安全ZIP → 审阅条件和来源 → 选择地图上下文、建立分析任务并在 Step 3 主动提交作者外部图（如案例提供）→ 在测试副本修改参数/数据触发复核，修订初稿 → 导出 Word 和追溯包。不要要求评委安装依赖、执行notebook或重做外部计算。

## 开发者参考

`developer-reference/`含三案各自开发包，可能包含notebook和完整结果；只用于人工验收和溯源，不得提供给被测模型。总包不含宏原件 source-review 包。

## 来源、许可与校验

各评委ZIP内含来源元数据/文件映射和逐文件hash（以子包manifest为准）。本总包的 `FILE_SHA256.txt` 对六个嵌入ZIP给出文件SHA256和大小。每个ZIP均执行CRC完整性检查；`ZIP_CRC_REPORT.txt`记载结果。评委包内容不包含 `.xlsm` 原件或完整分析notebook。子包源文件/CSV具体边界以包内README为准。

## 验收边界
三案均仅在各自公开方法—测量记录—数据—产出映射范围内通过样本验收，不代表通用科学能力或跨领域benchmark。缺少原始手写记录，故不构成OCR验证。其他不完整候选（包括未形成完整链条的电化学材料）不纳入。
