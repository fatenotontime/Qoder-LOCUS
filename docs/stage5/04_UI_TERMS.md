# 阶段5 UI 术语与文案规则

> 用户 2026-11-17 定：**能用 ≤4 字概括、或架构文档已定义的，不许写长句；不得过度说明。**
> 本表是前端文案的唯一依据；自验收每轮单开"简洁性检查"。

## 1. 七入口（职责表述即文案上限）

| 入口 | 核心职责 | 界面提示（短） |
| --- | --- | --- |
| 课题展示 | 看研究问题、子问题、进展与待办 | 研究问题与待办 |
| 文献整理 | 收集论文条目、附件；导入/连接 Zotero | 条目与附件；不强制解析 |
| 领域知识积累 | 从选中文献提取研究数据、条件、论据、思路，等待人审 | 选文献＋写目的，才提取 |
| 实验方案管理 | 上传、解析、完善方案，生成图 | 上传原件直接解析；版本固定 |
| 实验执行与记录 | 创建执行、引用方案、调整本次安排、逐步补记录与数据 | 先准备稿，确认快照后再记录 |
| 数据处理与分析 | 选上下文、推荐方法与验收项、接收结果、生成分析初稿 | 选上下文，推荐与验收项 |
| 上下文 AI 对话 | 围绕课题或选定材料讨论 | 带上下文讨论；采纳需确认 |

## 2. 对象术语（正文一律用左列短词）

课题 · 子问题 · 文献条目 · 附件 · 知识卡 · 方案 · 版本 · 快照 · 准备稿 · 差异 · 执行 · 事件 · 样品 · 测量 · 数据表 · 分析任务 · 上下文 · 结果 · **分析初稿** · 对话 · 采纳。

注：对象类型名仍为 `PreliminaryReportRecord`（初步报告），**界面统一显示「分析初稿」**；旧文档里的"初步报告"以本表为准。

## 3. 必须保留的硬标记（不得删减、不得改写）

定位不足 · 时长未知 · 未确认 · 不可复现 · 未配置 · 非作者原始 · 记录不改快照 · 源方案不影响本次 · 未实现 · 未验证。

这些是判断依据，不是说明文；短句即可，但不得省略。

## 4. 禁则

1. 禁补白句：「这是」「说明」「注意」「系统会」「您可以」。
2. 禁教学中介：类比、举例、"≠"式解释对比。
3. 禁同一信息两处重复（提示条与面板各写一遍）。
4. 折叠区标题 ≤ 12 字；按钮 ≤ 6 字。
5. 括号内不写次要限定（如"（hash 固定，不随加载重算）"），约束移入文档。

## 5. 本轮清理示例（节选）

| 位置 | 清理前 | 清理后 |
| --- | --- | --- |
| 导航提示 | 文献整理：论文条目≠文件；收藏/导入附件不触发 AI 解析 | 条目与附件；不强制解析 |
| 中栏注 | 定位不足：未能在原件中精确匹配该引文，已展示完整原件。 | 定位不足：显示完整原件。 |
| 中栏注 | 原图归档（不压缩转码）；识别结果在右栏，须人工确认。 | 原图归档；识别在右栏，须确认。 |
| 执行注 | 系统不虚构开始时间；实际开始由人记录。 | 由人记录，系统不代填。 |
| 表格注 | 点击中间原件或最大化视图中的单元格可定位；定位后再改数值（需原因）。 | 点单元格定位；改值需原因。 |
| 折叠标题 | 从论文附件重构（标 reconstructed，非作者原始方案） | 从论文重构（非作者原始） |
