# 阶段5 暂藏 / 未实现功能登记

> 5B 要求：把暂时藏起或尚未实现的功能登记为清单，作为前端协作依据。
> **不得用“后面优化”悄悄删需求；功能尚未实现也不能写成只是隐藏。** 每项必须如实标注当前状态。
> 维护：任何前端简化、折叠或暂缓都要在此登记。
