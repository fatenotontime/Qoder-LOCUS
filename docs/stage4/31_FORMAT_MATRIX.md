# 阶段4 · 格式类覆盖矩阵与语料门禁（A1+A4）

> 泛用性判据：**跨格式类 + 跨来源**，不以单一来源（SLAC 48 csv）的文件数为准。
> 解析契约：规则只在声明的 `FormatProfile` 内生效；`auto` 仅判定一次，可人工 override（页面「格式」下拉 / API `profile`）。

## 1. Profile 契约

| profile | 适用 | 规则 |
| --- | --- | --- |
| `plain-table` | 单表矩形（表头在首行） | 不切块；单/两级表头自动判定 |
| `enzymeML-blocks` | 标题行 + 空行分块 + 合并单元格两级表头 + 块标记行 | `splitBlocks` 逐块成表；标记行保留原样仅标注 |

`detectProfile` 判定边界（合成夹具逐条锁定，见 `tests/format-matrix.test.ts`）：
- 多块或有标题行 → blocks；
- 两级表头须符合**合并单元格**语义：第二级在首级空缺处有续列，且第二级至少含一个**非数值**单元格（纯数值行是数据，不是列名——类13 反例）；
- 第二级首格像行号（r0/r1）→ 单级。

## 2. 格式类矩阵（16 类合成夹具 + 3 跨来源真实 csv）

| 类 | 场景 | 期望 |
| --- | --- | --- |
| 1 | plain 逗号矩形 | 列名/行数正确，profile=plain-table |
| 2 | TSV | 制表符分隔 |
| 3 | 引号内含逗号与换行 | 单元格逐字保留 |
| 4 | CRLF + BOM | 与 LF 无 BOM 同构（hash 亦同，见 A2） |
| 5 | 首尾全空列 | 裁剪，不产生 colN 占位 |
| 6 | 合并两级表头 | 组名前向填充 `P/Name` 等 |
| 7 | 单级表头+列表数据 | 首行数据不被吞为第二级 |
| 8 | 多表叠放（空行分隔） | 逐块成表 |
| 9 | 标题行+块标记行 | 表名带 ` · 标题`；标记行保留仅标注（≤表头半数非空且前缀列） |
| 10 | 键列独占占位行 | 丢弃（非测量行） |
| 11 | 仪器导出（首行无分隔符） | 422 明确拒绝，不硬解析 |
| 12 | 前置标题行 | 422 明确拒绝 |
| 13 | 不规则表头（中间空列）+数值行 | 单级；占位列明示 `col2`，不补造列名 |
| 14 | 仅表头 / 空文件 | 422 拒绝 |
| 15 | profile 人工 override | 优先于 auto（分块文件强制单表→1 张） |
| 16 | 显式 headerRows 1/2 | 与 auto 一致处不漂移 |
