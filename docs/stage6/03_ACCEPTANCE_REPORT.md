## 实测证据（同轮）

- 测试：**176 通过**（`node --test tests/*.test.ts`）。新增 `references.test.ts`、`export.test.ts`、`stage6-exploratory.test.ts`。
- **6B 探索性验收**（`tests/stage6-exploratory.test.ts`，真实路由＋隔离实例，用内部达尔文包数据）：
  - **正常链路**：课题/子问题 → 文献(draft)＋数据表 → 方案（时长未知不按 0）→ 执行准备稿（登记缺项差异）→ 确认快照 → 样品/测量 → 分析任务＋推荐（冻结快照）→ 结果（可复现判定）→ 报告块（AI 草稿＋人工判断）→ 草稿确认 → 回查（块→结果→任务→表→测量→执行→方案）→ 改动命中 → Word/追溯包 → 整体导出/隔离恢复。
  - **重复/并发**：同内容导入 409 并给已有原件；推荐运行中重复 409。
  - **失败恢复**：对话取消→在途结果丢弃不写回；重试→写回 done。
  - **中途离开**：JsonFileStore 落盘，**重启新实例**后报告块与历史仍在。
- **DOCX 真实性**：生成件经 **office-docx MCP `read_context` 读回**，得到 9 个段块，顺序/性质/引用正确——Word 可打开，非"看似 zip"。
- **离屏渲染**：Edge headless 截图主界面正常（无白屏/致命 JS 错误）。

## 缺陷 / 未实现（如实）

- 报告块 `contextList`（与明确引用 `refs` 分开）**未单列**：目前块只有 `refs`，整体上下文由报告级 `pinned.snapshotHash` 覆盖。→ 记入 ADR-0020/0021，列为后续补齐项。
- **命中面板无可视化**：`/api/change-hits` 仅有接口，界面未做命中列表。
- **PDF 导出**未做（仅 DOCX）。
- 追溯包只对**论文附件**做许可过滤并入包；内部结果/分析文件不随包分发（在版本索引中按 id/版本引用）。
- 前端为满足简洁规则，说明文案已压缩（自验收简洁专项轮已做）。
