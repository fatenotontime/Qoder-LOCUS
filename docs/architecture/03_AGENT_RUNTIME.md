# 阶段2 · Agent Runtime 契约

> 03 §Agent Runtime。AI 解析/抽取/模板/建议/解释**都是草稿**；科学状态与人工认可分开。

## 1. 任务类型（本轮范围）

文献解析/抽取、命名与比较、方案拆解/模板、暂停风险建议、方法建议、结果解释、报告块、编辑影响分析。
**AI 重排：不接入（仅占位）。**

## 2. 统一流程

```text
明确触发 → 固定 ContextSnapshot → schema 约束提示词 → 服务端调用
→ 原响应留存(授权业务数据区) → 结构/来源校验 → 草稿入队 → 人工动作
```

## 3. 状态与语义

- 任务状态：`queued | running | succeeded | failed | cancelled`。
- 复核状态（另存）：`draft | reviewed | adopted | excluded | withdrawn`。
- **`succeeded` 只表示调用完成，不代表内容确认**。

## 4. 可靠性

- 超时、重试、并发控制、熔断；**重试幂等**，不产生重复卡片/重复正式记录。
- **旧响应晚到不得覆盖新编辑**（置 `stale`，保留供查）。
- 连续失败 → 减少重复请求，显示可恢复错误。
- 模型/解析不可用 → 保留原始与人工录入；**不用模板假话假装完成**。

## 5. 模型适配（开发 ≠ 运行）

- 适配层把供应商与产品对象分开；开发用 DeepSeek，**运行时模型另择**。
- 记录（可得时）：模型版本、提示词版本、输入快照 hash、原响应、人工修订；**会话 Key 不写入日志/Git/导出**。
- 会话 Key 可由本机「模型设置」保存到 `<数据目录>/ai-config.json`（默认不入库；ADR-0024）；环境变量优先。可用模型列表见 `POST /api/ai/models`。
- 无凭据**不硬编码、不自动调用付费**。

## 6. 安全边界

- 文档内指令视为**待处理数据**，不得改变任务权限、越过上下文范围、读取其他会话。
- 上下文先选范围再抽片段；长文截断/摘要**留痕**，不静默丢关键单位条件。

## 7. 影响分析（新增必做，03 §Edit Impact）

- 输入：changeSetId、base/new revision、改动字段前后值、原因、课题/子问题、方案关键步骤、执行是否已开始/暂停、有关样品/测量/结果/报告引用、已知依赖、适用证据与缺项。
- 只收**相关**上下文；发送清单可展开；**不逐项推荐理由**。
- 输出见 `01_DOMAIN_SCHEMA.md` §5。
- **时间传播由确定性模型给；AI 只补语义评估**；`失败/未配置 ≠ 无影响`；新改动 ⇒ 旧分析 `stale`。
- 生产阶段须用真实已授权测试模型跑出**至少一个有影响、一个无足够依据、一个失败**用例并记成本（阶段6后）。
