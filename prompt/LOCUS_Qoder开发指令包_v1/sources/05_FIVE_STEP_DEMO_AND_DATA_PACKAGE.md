## 五步路线 草案待确认

1. 首页下载公开测试包，导入演示工作区；载入包内课题/子问题说明，展示来源与原始材料，而非预先把所有AI任务标完成。
2. 解析审阅：抽查一张文献证据卡，打开方案图及记录；背景可处理其余材料。保留人工确认与未复核区别，不用一键导入消灭核心审阅。
3. 选择原始数据与上下文地图，建立分析任务；可使用包内原作者/已复现的外部分析产物并提交方法，不要求评委另装软件或等待真实实验。
4. 生成局部分析初稿，点击数值回到结果/输入/原始记录；实施一次明确标为测试的上游修订，检查复核提示，不伪造原始开放数据被修正。
5. 接受/保留快照，导出Word初稿及追溯包，验证版本和来源。

五步是用户任务，不许藏长串配置/外部注册/手动建库要求。具体点击次数、用时和包大小由实际测试回填。不可虚称“一步”完成大量不可见人工审阅。正式访客API凭据/预算方案仍待决。

## 测试包内容契约

- README：五步、文件用途与预期可见结果。
- 课题/子问题：如由LOCUS从公开研究整理则标编写/改编，非原作者立项书。
- 文献/证据材料：许可允许再分发的文件及具体页码；不允许则只放引用与链接。
- 实验方案：原公开procedure；若由事后实验记录重构，明示重构，不能假装原计划。
- 真实公开实验记录＋对应原始数据；缺少时不得用合成物伪装补齐。
- 外部分析结果、方法/参数/脚本或项目文件；标原作者产物还是LOCUS复现。
- 一份明确标注的修改测试说明，不覆盖原始来源。
- manifest：文件路径、来源、版本、许可证、哈希及对象映射；署名/许可文本，禁止私人SRTP内容。
- 开发回归预期与评委输入分开，不能让待测AI读预期答案冒充分析能力。
